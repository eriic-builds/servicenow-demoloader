About this prototype & storage
Use a pre-created API-enabled Machine account for recommended onboarding. Chat supports reviewed account setup and incident/Knowledge article creation (Draft or Published) with exact source read-back and recovery. The config form itself never provisions anyone. Knowledge checkout/revision, content updates, bulk re-seeding and cleanup are not yet enabled.
Installed resources stay inside the skill. Configs and history use the separate output library: Loading from local service. Credentials and live execution authority stay protected in Windows local application data, never in the output library.
